কী ঠিক করা হয়েছে
-----------------
১. পুরোনো অ্যাপ chart-এর নিচের লাল/সবুজ trade button-কেও candle pixel মনে করতে
   পারত। এতে DOWN bias তৈরি হতো। v2 শুধু mobile chart band বিশ্লেষণ করে।
২. UP এবং DOWN-এর scoring rule এখন পরস্পরের হুবহু mirror।
৩. অস্বাভাবিক বড় coloured object candle হিসেবে বাদ দেওয়া হয়।
৪. একই signal পরপর ২টি scan-এ না এলে UP/DOWN দেখায় না।
৫. “confidence” নয়, “setup strength” দেখায়—এটি win probability নয়।
৬. rising, falling এবং flat market-এর deterministic self-test যোগ করা হয়েছে।
৭. qxbroker.com DNS error হলে official quotex.com address স্বয়ংক্রিয়ভাবে চেষ্টা করে।
৮. error page-কে আর ভুলভাবে LIVE PAGE দেখায় না।

APK বানানোর সহজ নিয়ম
---------------------
১. ZIP extract করুন।
২. পুরো qx-native-demo-signal-local folder একটি নতুন GitHub repository-তে upload করুন।
৩. GitHub-এর Actions tab খুলুন।
৪. “Build Android Demo APK” workflow চালান।
৫. সফল run-এর Artifacts থেকে “QX-Native-Demo-APK-v2” download করুন।
৬. ZIP খুলে app-debug.apk install করুন। পুরোনো APK signature conflict দিলে আগে
   পুরোনো অ্যাপ uninstall করুন।

v2.2 LIVE DEMO PAGE FIX
=======================

- App এখন marketing home page নয়, official /en/demo-trade page সরাসরি খোলে।
- qxbroker.com থেকে market-qx.trade / market-qx.pro-তে official redirect হলেও
  app সেটিকে LIVE DEMO হিসেবে গ্রহণ করে এবং chart analysis শুরু করে।

- Currency/asset বদলানো যাবে Quotex-এর নিজের live page-এর selector থেকে।
- Selected asset/session রেখে RELOAD CHART কাজ করে।

সীমা: Quotex-এর private AI/API app-এর মধ্যে কপি করা হয়নি। Signal হলো on-device
multi-filter candle analysis; profit বা 8/10 win guarantee নয়। Demo-তে test করুন।

v2.3 HIGH-CONFIRMATION ENGINE
=============================

- কমপক্ষে ১৬টি candle এবং ১৫ point-এর মধ্যে ৯ point confluence লাগে।
- Short/medium/long trend, EMA, MACD impulse, RSI, momentum, candle balance,
  breakout, trend efficiency এবং range position একসঙ্গে পরীক্ষা করে।
- Choppy, low-volatility, sudden shock, conflicting trend ও overextended market
  হলে UP/DOWN না দিয়ে WAIT দেখায়।
- একই direction পরপর ৩টি scan-এ নিশ্চিত হলে signal দেখায়।
- UP ও DOWN scoring পুরো mirror; কোনো দিককে অগ্রাধিকার দেওয়া হয়নি।
